Next.js Standalone Deployment Flow

Code RepositoryOne-time change
  • 1Set output: "standalone" in next.config.ts
Trigger build
JenkinsBuild & package
  • 2Install dependencies and build (Node 22)
  • 3Copy static assets, then zip standalone/public → standalone/.next/static → standalone/.next/
Copy zip
Application ServerDeploy & run
  • 4Extract zip in the application folder
  • 5Start standalone/server.js with PM2

Zip artifact structure

document-automation-sit.zip
└── standalone/deployment folder
├── server.jsentry point started by PM2
├── package.jsonapp metadata
├── node_modules/trimmed – only runtime packages
├── .next/
│ ├── server/compiled application
│ ├── static/CSS, JS files copied from .next/static
│ └── *.json, BUILD_IDbuild manifests
└── public/images, fonts, files copied from public

What the server no longer needs

  • No npm install
  • No build step
  • No full node_modules
  • No source code
  • Only Node 22 + PM2
